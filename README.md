# 小小棋盘 · 儿童棋类与全脑益智乐园

> 🌟 一个纯前端、零依赖、100% 离线运行的少儿全脑思维与课标伴学聚合平台。  
> 包含 **29 款益智对弈游戏** + **1 款独立伴学模块**，深度适配手机、平板与桌面端，独创 **四大自适应沉浸舞台架构**。

## 怎么打开

- **最简单**：双击 `index.html` 即可在任意浏览器直接畅玩（纯本地文件离线可用，数据持久化保存在浏览器中）。
- **启用 PWA 离线应用与全屏桌面模式**：在项目根目录启动静态服务器（如 `python -m http.server 8000` 或 `npx serve .`），浏览器访问 `http://localhost:8000`，首次加载后 Service Worker（`v57`）自动缓存全部资源，后续断网即可秒开。

## 益智游戏与规则

- **五子棋** 15×15，黑先，横竖斜先连成五子即胜。
- **围棋** 9×9，黑先，白棋贴 6.5 目；无气提子、禁止自杀与打劫；双方连续停一手终局，用数子法（子 + 围空）计算胜负。
- **跳棋** 121 孔六角星盘，双方各 10 枚；可走一步或连续跳跃，先把 10 枚全部送进对面三角星者胜。**反赖皮规则**：目标区的格子若被腾空后被对方棋子占据，也视为己方占满——对方赖在营地不走反而送你获胜，杜绝死锁。
- **象棋** 10×9，红先；完整规则（蹩马腿、塞象眼、炮翻山、兵过河、士将限九宫、将帅不可照面），将死或困毙判负，60 回合无吃子或三次重复局面判和。
- **数独** 4×4（2×2 宫）/ 6×6（2×3 宫）/ 9×9（3×3 宫）三种盘面，由易到难循序渐进；所有盘面由生成器保证 **唯一解**。
- **数字华容道** 3×3 / 4×4 / 5×5，从完成态随机走子打乱（天然保证有解），把数字按 1→末尾排好。
- **记忆翻牌** 6 / 8 / 12 对 Emoji 配对，3D翻牌动画 + 提示偷看，锻炼短时记忆。
- **24 点** 四张牌加减乘除凑 24，内置有理数求解器 **保证每局有解**；两两组合式操作，适合低龄孩子。
- **口算训练营** 四档梯度：启蒙 10 内加减 → 基础 20 内加减 → 进阶乘法表与百内 → 挑战两位数乘除。每轮 10 题计时挑战，连击奖励、**错题本**自动收录并重练、正确率进步曲线；**答案区全自绘保护，彻底杜绝手机弹出系统软键盘**。
- **魔法汉诺塔 (新增)** 3~6 层经典数学递归挑战，大环不压小环，从 A 柱挪至 C 柱；配备理论最少步数指示与智能推演提示，锻炼逆向空间规划思维。
- **奇妙点灯 (新增)** 3×3 ~ 5×5 矩阵空间反转推理，点击星星带动相邻十字翻转，数学生成器保证 **100% 可解**，美轮美奂星空音阶与星光闪烁特效。
- **像素数织 (新增)** 5×5 / 8×8 / 10×10 三档，按行列数字提示涂出隐藏像素画；支持涂色 / 标叉双模式与**按住拖动连涂**，已确定的行列提示自动变淡，「检查」一键标红涂错格。
- **推理密码 (新增)** 经典 Mastermind 演绎推理：破译 4 格不重复颜色密码，8 次机会；🟣 表示颜色位置都对、⚪ 表示颜色对位置不对，支持悔棋与位置提示，失败自动揭晓答案。

## 数独 · 学习路线

| 盘面 | 定位 | 简单 | 一般 | 困难 |
| --- | --- | --- | --- | --- |
| 4×4 | 幼儿入门，认识规则 | 挖 5 格 | 挖 8 格 | 挖 10 格 |
| 6×6 | 过渡，学会扫描行列 | 挖 12 格 | 挖 17 格 | 挖 21 格 |
| 9×9 | 经典，向高手进阶 | 45 提示数 | 37 提示数 | ≥31 提示数 |

教学功能：
- **📖 数独学堂（分步教程）**：4 节互动课——「认识数独」（行/列/宫规则）→「唯一余数法」→「隐藏唯一法」→「6×6 小小挑战」。
  像小老师一样逐步引导：橙色框标出目标格和高亮区域，孩子填对了就夸奖并进入下一步，填错会换个说法再讲一遍，
  卡住了可以「看答案」示范。后三课的盘面每局随机生成，学的是方法而不是背答案。
- **技巧提示**：提示一手会先指出填错的位置，再按难度依次用「唯一余数法」「隐藏唯一法」讲解该填哪格、为什么；难题兜底给「综合排除」演示。
- **铅笔标注**：✏️ 笔记模式下点数字记候选小字，填入正确数字后自动清理同行列宫的笔记。
- **即时纠错**：填错的数字红色高亮，「👀 检查」一键统计错误数。
- **数字余量**：键盘上每个数字显示还剩几个没填完，帮助孩子建立全局意识。
- 支持键盘（方向键移动、1-9 填数、N 切换笔记）与触屏。

| 记忆翻牌 | 短时记忆、专注力 | 6 对 / 8 对 / 12 对 |
| 24 点 | 四则运算、心算 | 数字 1~9 / 1~10 / 1~13 |

| 像素数织 | 观察推理、空间逻辑 | 5×5 / 8×8 / 10×10 |

都有步数/用时统计、悔棋（华容道）、提示（华容道推荐走法、翻牌偷看、24 点给出解法思路、口算给「凑十/破十/口诀」思路），
成绩计入战绩页，进度自动保存、断网可玩。

### 口算训练营 · 练法

- 每轮 10 题，答完立即出成绩：正确率 ≥ 80% 判胜，计入战绩；
- **连击奖励**：连对 3 题起触发 🔥 鼓励，最佳连对会记入结果；
- **错题本**：答错的题自动收录（同题去重），点「错题重练」专攻弱点，答对即从错题本移除；
- **提示**：加法想「凑十」、减法想「破十/想加法」、乘除背口诀倒着想；
- **进步曲线**：最近成绩的正确率记录在训练页下方，孩子能看到自己在变强。

## 电脑难度

| 棋类 | 简单 | 一般 | 困难 |
| --- | --- | --- | --- |
| 五子棋 | 一层贪心 + 随机 | 2 层 Alpha-Beta | 5 层 Alpha-Beta + 增量窗口计分 |
| 围棋 | 随机守形 | 启发式打分 | 候选点 + 蒙特卡洛模拟对局 |
| 跳棋 | 偏好前进的随机 | 单步最优推进 | 4 层 Top-K 极小化极大（含掉队棋子惩罚与进营激励） |
| 象棋 | 1 层 + 大随机 | 3 层迭代加深 | 5 层迭代加深 + 子力位置表 |
| 数独 | 多挖空 + 唯一解约束 | 中等挖空 | 少提示数（更依赖技巧） |

电脑思考都有时间上限（约 0.25s / 0.6~1s / 1.2~1.6s），不会把页面卡死。

## 离线与数据

- 数据键：`localStorage` 前缀 `kidboard.v1.`（设置、战绩、对局存档、口算错题本与成绩）。
- 浏览器禁用存储时自动降级为内存模式，功能仍可用（刷新后丢失）。
- 设置页可导出 JSON 备份、导入恢复、一键清空。
- **断网可玩**：Service Worker 缓存全部资源，页面本身走「网络优先、失败回退缓存」，所以断网也能正常打开。

## 自动更新（联网即更新）

发布新版本后，用户无需手动清理缓存：

1. 改代码时把 `sw.js` 里的 `CACHE` 版本号 +1（如 `kidboard-v7` → `kidboard-v8`）。
2. 用户联网打开页面 → 浏览器发现 `sw.js` 有变化 → 新版本后台安装完成。
3. 页面检测到新版本 → **先保存当前对局进度** → 提示「✨ 发现新版本，正在更新…」→ 约 1.2 秒后自动刷新到最新版，刷新后可继续未下完的棋。
4. 兜底策略：页面回到前台、每 30 分钟各静默检查一次；设置页也有「🔄 检查更新」按钮可手动触发。

## 动效

`js/fx.js` 提供全站动效：胜利彩带粒子（Canvas）、元素弹跳 / 晃动、表情飘浮、大字横幅；
首页卡片逐个入场、按钮按下回弹、结果弹窗表情弹跳、口算对错即时反馈动画。

## 部署到 Cloudflare Pages

纯静态站点，无需任何服务端。三种方式任选：

**方式 A · 脚本一键部署（推荐）**

```bash
# 1. 首次使用先登录（浏览器授权一次即可）
npx wrangler login

# 2. 一键部署
bash deploy.sh
# 或在 CI / 无浏览器环境用 API Token：
# export CLOUDFLARE_API_TOKEN=你的令牌 && bash deploy.sh
```

部署成功后会输出线上地址（形如 `https://kidboard.pages.dev`）。
项目名可通过环境变量覆盖：`CLOUDFLARE_PROJECT=myname bash deploy.sh`。

**方式 B · 控制台直传**

[Cloudflare Dashboard](https://dash.cloudflare.com) → Workers & Pages → Create → Pages →
Upload assets，把 `deploy.sh` 打包出的 `.deploy/` 目录（或整个项目目录）拖进去即可。

**方式 C · 连 Git 仓库自动部署**

推到 GitHub/GitLab 后在 Pages 里选择仓库，构建命令留空、输出目录填 `/`（根目录）。

> 为什么选 Pages 而不是 Workers：本项目没有服务端逻辑，Pages 直传零配置；
> Workers 适合带 API/边缘函数的项目。若以后要加在线对战，再迁移到 Workers（assets + Durable Objects）也不迟。
>
> 缓存策略已在 `_headers` 里配好：`sw.js` 与入口页不缓存（保证更新即时生效），css/js 缓存一天。
