# 小小棋盘 · 儿童棋类乐园

一个纯前端、可离线运行的儿童棋类聚合平台。包含 **五子棋、围棋、跳棋、中国象棋、数独** 五种玩法，
棋类均支持 **人机对战（简单 / 一般 / 困难三档）** 与 **本地双人对战**，所有数据保存在本机浏览器中。

## 怎么打开

- 最简单：双击 `index.html` 即可（本地文件方式也是离线可用的，数据存在浏览器里）。
- 想启用「添加到桌面 / 断网缓存」：在本目录执行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`，
  首次加载后 Service Worker 会把全部资源缓存下来，之后断网也能打开。

## 功能

| 模块 | 说明 |
| --- | --- |
| 首页 | 四张游戏卡片、未完成的对局续玩入口、累计战绩 |
| 对局 | 棋盘自适应（含手机竖屏）、电脑思考提示、悔棋、提示一手、认输、重新开始 |
| 战绩 | 胜/负/和统计、总胜率、最近 100 局明细（可单条删除） |
| 设置 | 三套主题（清新/木质/夜间）、音效开关、坐标显示、每种棋的默认难度、数据导出导入与清空 |

## 棋类与规则

- **五子棋** 15×15，黑先，横竖斜先连成五子即胜。
- **围棋** 9×9，黑先，白棋贴 6.5 目；无气提子、禁止自杀与打劫；双方连续停一手终局，用数子法（子 + 围空）计算胜负。
- **跳棋** 121 孔六角星盘，双方各 10 枚；可走一步或连续跳跃，先把 10 枚全部送进对面三角星者胜。
- **象棋** 10×9，红先；完整规则（蹩马腿、塞象眼、炮翻山、兵过河、士将限九宫、将帅不可照面），将死或困毙判负，60 回合无吃子或三次重复局面判和。
- **数独** 4×4（2×2 宫）/ 6×6（2×3 宫）/ 9×9（3×3 宫）三种盘面，由易到难循序渐进；所有盘面由生成器保证 **唯一解**。

## 数独 · 学习路线

| 盘面 | 定位 | 简单 | 一般 | 困难 |
| --- | --- | --- | --- | --- |
| 4×4 | 幼儿入门，认识规则 | 挖 5 格 | 挖 8 格 | 挖 10 格 |
| 6×6 | 过渡，学会扫描行列 | 挖 12 格 | 挖 17 格 | 挖 21 格 |
| 9×9 | 经典，向高手进阶 | 45 提示数 | 37 提示数 | ≥31 提示数 |

教学功能：
- **技巧提示**：提示一手会先指出填错的位置，再按难度依次用「唯一余数法」「隐藏唯一法」讲解该填哪格、为什么；难题兜底给「综合排除」演示。
- **铅笔标注**：✏️ 笔记模式下点数字记候选小字，填入正确数字后自动清理同行列宫的笔记。
- **即时纠错**：填错的数字红色高亮，「👀 检查」一键统计错误数。
- **数字余量**：键盘上每个数字显示还剩几个没填完，帮助孩子建立全局意识。
- 支持键盘（方向键移动、1-9 填数、N 切换笔记）与触屏。

## 电脑难度

| 棋类 | 简单 | 一般 | 困难 |
| --- | --- | --- | --- |
| 五子棋 | 一层贪心 + 随机 | 2 层 Alpha-Beta | 5 层 Alpha-Beta + 增量窗口计分 |
| 围棋 | 随机守形 | 启发式打分 | 候选点 + 蒙特卡洛模拟对局 |
| 跳棋 | 偏好前进的随机 | 单步最优推进 | 4 层 Top-K 极小化极大 |
| 象棋 | 1 层 + 大随机 | 3 层迭代加深 | 5 层迭代加深 + 子力位置表 |
| 数独 | 多挖空 + 唯一解约束 | 中等挖空 | 少提示数（更依赖技巧） |

电脑思考都有时间上限（约 0.25s / 0.6~1s / 1.2~1.6s），不会把页面卡死。

## 离线与数据

- 数据键：`localStorage` 前缀 `kidboard.v1.`（设置、战绩、对局存档）。
- 浏览器禁用存储时自动降级为内存模式，功能仍可用（刷新后丢失）。
- 设置页可导出 JSON 备份、导入恢复、一键清空。

## 目录结构

```

manifest.webmanifest  PWA 配置
sw.js                 Service Worker 离线缓存
css/style.css         样式与主题变量

js/sfx.js             WebAudio 合成音效（无外部资源）

js/games/*.js         五种玩法的规则、渲染与 AI

deploy.sh             一键部署脚本
```

## 部署到 Cloudflare Pages

纯静态站点，无需任何服务端。三种方式任选：

**方式 A · 脚本一键部署（推荐）**

```bash
# 1. 首次使用先登录（浏览器授权一次即可）
npx wrangler login

# 2. 一键部署
bash deploy.sh
# 或在 CI / 无浏览器环境用 API Token：
# export CLOUDFLARE_API_TOKEN=你的令牌 && bash deploy.sh
```

部署成功后会输出线上地址（形如 `https://kidboard.pages.dev`）。
项目名可通过环境变量覆盖：`CLOUDFLARE_PROJECT=myname bash deploy.sh`。

**方式 B · 控制台直传**

[Cloudflare Dashboard](https://dash.cloudflare.com) → Workers & Pages → Create → Pages →
Upload assets，把 `deploy.sh` 打包出的 `.deploy/` 目录（或整个项目目录）拖进去即可。

**方式 C · 连 Git 仓库自动部署**

推到 GitHub/GitLab 后在 Pages 里选择仓库，构建命令留空、输出目录填 `/`（根目录）。

> 为什么选 Pages 而不是 Workers：本项目没有服务端逻辑，Pages 直传零配置；
> Workers 适合带 API/边缘函数的项目。若以后要加在线对战，再迁移到 Workers（assets + Durable Objects）也不迟。
>
> 缓存策略已在 `_headers` 里配好：`sw.js` 与入口页不缓存（保证更新即时生效），css/js 缓存一天。
