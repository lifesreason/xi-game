# 2026-09-20

## 镜像线上站点到 code/ 目录

- 目标：把 https://game.leqi.qzz.io 的站点代码下载到项目新增的 `code/` 目录。
- 站点是 Cloudflare 托管的纯静态 PWA（小小棋盘 · 儿童棋类乐园），无构建产物、无后端。
- 资源清单来源：`sw.js` 的 `ASSETS` 预缓存数组（最可靠，直接给出全部静态资源路径）。
- 实现：`/tmp/mirror_site.py` —— 按清单并发下载（8 线程），再从已下载的 HTML/CSS/JS 中正则二次挖掘引用补漏。
- 结果：**37 个文件、592K**，与本地项目 `js/games` 逐文件比对无差异，`index.html` 的 36 处引用全部可解析，无空文件。
- 坑：并发下载 `js/games/slidepic.js` 时偶发 `SSL CERTIFICATE_VERIFY_FAILED: Hostname mismatch`（Cloudflare 边缘节点证书抖动），第二轮串行重试即成功 —— 批量抓取建议保留重试轮。
- 版本差异（线上比本地新）：线上 `sw.js` 为 `kidboard-v43`，本地为 `kidboard-v39`；`index.html` / `css/style.css` / `js/app.js` / `js/store.js` 内容均有差异，`manifest.webmanifest` / `js/sfx.js` / `js/fx.js` / `js/boardkit.js` 相同。

### 复用要点
- 镜像静态 PWA 时，优先找 `sw.js` / `service-worker.js` 的预缓存清单，比爬 HTML 链接完整得多。
- 本机无 `wget`，用 Python `urllib` + `ThreadPoolExecutor` 即可。
