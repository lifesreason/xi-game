# 小小棋盘：移动端修复 + 全面质变升级

源码在根目录，`.deploy/` 为部署副本（最后用 deploy.sh 同步），`sw.js` 缓存版本号需 +1。

## 一、Bug 修复
1. **数独 6×6 宫线错位**：`js/games/sudoku.js:451-459`（练习模式）与 `:724-732`（学堂模式）两处，把粗线判定拆开——竖线只判 `i % bw === 0`，横线只判 `i % bh === 0`。同时顺带检查数独"检查/完成"闭环（`after()`/`checkNow()`）确保提示正确。
2. **跳棋死锁缺陷**：`js/games/checkers.js` 的 `isWin`(:121) 改为标准反赖皮规则——目标区每格被"己方或对方"棋子占据即视为己方占满（对方棋子赖在你营地反而送你获胜），消除死锁。
3. **跳棋 AI 提升**：评估函数加入"掉队棋子惩罚 + 搭桥通道奖励"，hard 难度搜索加入己方营地清空奖励；`doMove` 连跳音效判定改为按路径实际跳跃数而非距离差。
4. **跳棋悔棋**：pvp/restore 下 snaps 与 history 的对应关系核对，避免多次悔棋错位。

## 二、全项目功能闭环审查
逐个核对 11 个游戏 + app.js 的存档恢复、胜负判定、undo、settings、SW 离线更新逻辑，修复发现的问题（如 app.js `applyUpdate` 双重 reload 可能打断用户操作、memory/game24/hanoi/lightsout 的边界情况）。重点：移动端触控热区（孔位/格子命中半径 ≥ 44px 逻辑换算）、软键盘规避、safe-area。

## 三、界面与交互"质的提升"（全面）
- **设计系统升级**（style.css）：更精致的配色/渐变/阴影体系，卡片立体感 + 玻璃拟态顶部，统一的动效曲线变量。
- **首页**：卡片入场交错动画、悬停/按压微交互、分类标签筛选动效、星星/徽章展示更醒目。
- **对局页**：棋盘入场动画、棋子落子/吃子/选中弹性动效（fx.js 增强）、胜利结算更华丽（彩带 + 奖杯 + 数据面板）、按钮 ripple 已有则统一质感。
- **移动端**：底部导航毛玻璃 + active 动效，全部触控目标 ≥ 44px，横屏/小屏（<350px）逐一适配。
- 保持 `prefers-reduced-motion` 支持。
